## 0. 问题

EXP-039 只用了一个家族的 judge（Qwen2.5 1.5B / 3B / 7B）。它的结论是：被骗起点主要由 judge 决定。

**主问题**：把 judge 换成同样大小、不同家族的 Llama-3.2-3B-Instruct（JL），其他都不变，被骗的程度和起点像 Qwen 3B judge（J3）吗？

## 1. 术语（新的只有两个）

- **JL**：冻结的 Llama-3.2-3B-Instruct（3.21B 参数），不看参考答案，prompt 同 Qwen judge（`code/judge39.py`，日期固定为模板默认值）。
- **平台高度 H̄**：一个 run 在第 101–150 步的被骗程度（第 6.1 节）。

## 6. 端点（运行前写定）

### 6.1 主端点：平台高度 H̄

- 对一个 run：取第 101–150 步（含两端）的全部训练 rollout 中宽松金标准判错的回答。n = 这些回答数，f = 其中 G_cal + 1e-6 ≥ τ_len(J, P) 的个数（同 EXP-039 补充 7）。
- H̄ = (f/n − FPR0_len(J, P)) / (1 − FPR0_len(J, P))。τ_len、FPR0_len 取本格的值（`results/static_lenient.json`）。
- 格的值 = 种子的算术平均。
- 主比较：**D_P05 = H̄(P05×JL) − H̄(P05×J3)**，4 对 4 个种子，Welch t 区间，95%。P15 的同一比较（2 对 4）只作描述。
- EXP-039 的平台高度（同一定义，从 `../EXP-039/results/compact/` 算出，运行前已知）：

| 格 | 种子的 H̄ | 平均 |
|---|---|---|
| P05×J15 | 0.972、0.978 | 0.975 |
| P15×J15 | 0.982、0.948 | 0.965 |
| P05×J3 | 0.824、0.849、0.783、0.808 | 0.816 |
| P15×J3 | 0.719、0.622、0.657、0.619 | 0.654 |
| P05×J7 | 0.334、0.336、0.401、0.425 | 0.374 |
| P15×J7 | 0.534、0.411、0.438、0.272 | 0.414 |

### 6.2 次要端点：起点 t½

- t½(0.5)：EXP-039 的主定义，不变（5 步窗口，宽松金标准，本格的 τ_len，h ≥ 0.5 连续两个窗口，窗口错答 ≥ 20 条）。
- t½(0.3)：同上，阈值改为 0.3（EXP-039 发现 0.5 处的脆弱性）。
- 比较：EXP-039 的 AFT 模型（`../EXP-039/code/analyze39.py`，同 σ 先验），把 JL 两格加进去。报告 μ(P×JL) − μ(P×J3) 和 μ(P×JL) − μ(P×J15)，95% 剖面似然区间。
- EXP-039 对照数字（宽松）：t½(0.5) 格几何均值 P05×J15 19.4，P15×J15 21.0，P05×J3 25.8，P15×J3 37.0。t½(0.3)：P05×J15 13 / 15，P15×J15 17 / 17，P05×J3 18 / 19 / 15 / 18，P15×J3 19 / 23 / 31 / 19。

### 6.3 描述（不进判决）

- h 随步数的曲线（5 步窗口），叠在 EXP-039 的 J15、J3 曲线上。
- 被骗回答的形式（每格读 20 条，同 EXP-039 第 6.5 节）：长度、格式、"####"、错误类型。
- 第 0 步和最后的评测正确率、格式率、t½ 处的采样 KL。

## 7. 预测和判决规则（运行前写定）

### 7.1 两种"judge 主导"

- **按大小（任务给的预测，主预测）**：同样大小的 judge 行为相同，和家族无关。JL 像 J3。
- **按第 0 步能力**：被骗的程度由 judge 在第 0 步的辨别能力决定。JL 的 AUC 像 J15，所以 JL 像 J15。
- **家族特有**：两种都不对。例：Llama 对 Qwen 策略的错误不敏感的方式不同。

### 7.2 具体预测（"按大小"为真时）

- P05×JL 的 H̄ 在 0.67–0.97 之间（J3 的 0.816 ± 0.15）。D_P05 的 95% 区间在 [−0.15, +0.15] 之内（等价界 0.15 约等于 J15 和 J3 平台之差 0.16）。
- P05×JL 的 t½(0.5) 几何均值在 17–39 步（J3 的 25.8 的 1/1.5 到 1.5 倍）；|μ(P05×JL) − μ(P05×J3)| < ln 1.5 = 0.41。
- P15×JL（描述）：H̄ 约 0.50–0.80，t½(0.5) 约 25–56 步。

### 7.3 判决（主端点，P05 一行）

- **V1 按大小成立**：D_P05 的 95% 区间在 [−0.15, +0.15] 之内。
- **V2 按能力**：P05×JL 的 H̄ ≥ 0.90，并且 D_P05 的 95% 区间下界 > 0（比 J3 更容易被骗，接近 J15 的 0.975）。
- **V3 家族特有（更难骗）**：D_P05 的 95% 区间上界 < −0.15（比 J3 更难骗）。
- **V4 未决**：其他情况。按实测方差报告需要多少种子。
- **"按大小"被否定**：V2 或 V3 成立。
- 起点（次要）只用来看是否同向。如果起点和平台给出不同的判决，两个都报告，主结论按平台，并写明不一致。

## 8. 停止规则

- 全部 6 个 run 一次提交。中途不看结果做决定，不加种子，不加步数。
- 有 run 失败：按第 5 节重跑一次。重跑后仍失败：
  - P05 一行少于 3 个完成的种子 → 不做判决（V4），报告。
  - P15 一行缺失 → 只报告 P05 一行。
- **算力上限**：12 A100 小时（计法同 EXP-039：墙钟 × 卡数）。重跑前检查"已用 + 预计 ≤ 12"，不满足就不重跑。
- 静态闸门不过 → 不跑 RL（已通过）。
- 如果 P05×JL 四个 run 在第 101–150 步的宽松错答总数 < 200 条（策略几乎全对，平台不可估）→ 主端点不可识别，只报告起点。

## 9. 算力

- 冒烟实测：P05×JL 每步约 12–14 秒，评测约 40 秒；P15×JL 每步约 14 秒，评测约 67 秒。
- 预计：P05×JL 200 步约 1.2 小时 × 4 = 4.8；P15×JL 150 步约 1.1 小时 × 2 卡 × 2 = 4.4。静态闸门和冒烟约 0.25。**合计约 9.5 A100 小时**，上限 12。

## 10. 已知局限（运行前）

- 只有一个 Llama judge 尺寸。不能分开"家族"和"这一个模型的特性"。
- JL 的词表、chat 模板和 Qwen 不同。G = logit(Yes) − logit(No) 的刻度不同，但 G_cal 和 τ_len 是按每个 judge 自己的第 0 步数据定的。
- P15 只有 2 个种子。
- J3 的对照数字来自 EXP-039 的 run（261009），不是同时跑的。机器、环境和代码相同。
