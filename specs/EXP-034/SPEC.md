## 0. 问题

在 GRPO 下，奖励只来自一个冻结的 LLM judge。judge 看不到参考答案。
我们交叉变化策略大小（0.5B、1.5B）和 judge 大小（1.5B、7B），得到 2×2 格点。
问题：judge 被骗的速度，主要由"策略和 judge 的能力差距"决定，还是由"judge 本身的能力"决定？

三个假设：
- **H_gap（差距）**：被骗速度只取决于 judge 和策略的大小之比。
- **H_judge（judge 绝对能力）**：被骗速度只取决于 judge。策略大小没有影响。
- **H_policy（策略绝对能力）**：被骗速度只取决于策略。judge 大小没有影响。

为什么重要：H_gap 成立时，"judge 和策略一起变大"能保持监督有效。H_judge 成立时，只需要加大 judge。两者给出相反的工程建议。

## 1. 术语（每个只解释一次）

- **策略 P05**：sft-s2。Qwen2.5-0.5B 基座，在 2000 道 GSM8K 解答上做过一轮 SFT（EXP-013，种子 2）。线 5 的全部 run 都用它。
- **策略 P15**：Qwen2.5-1.5B 基座，用与 sft-s2 完全相同的 SFT 配方和种子（2）训练。本实验第 0 步做出。
- **judge J15**：冻结的 Qwen2.5-1.5B-Instruct（同线 5 的 judge A）。
- **judge J7**：冻结的 Qwen2.5-7B-Instruct。
- **格**：一个（策略，judge）组合。共 4 格：P05×J15、P05×J7、P15×J15、P15×J7。
- **G**：judge 的 logit("Yes") − logit("No")。prompt 同 EXP-021 主 prompt（不给参考答案，问"最终答案对吗"）。
- **G_cal**：G 上的一维逻辑回归，输出概率。每个 judge 一个，在两个策略的第 0 步样本 d0 上合并拟合。它就是奖励。
- **d0、d8**：第 0 步策略样本。d0 = RL 划分第 0–999 题各采样 2 次；d8 = 第 1000–1255 题各采样 8 次。T = 1.0。题目集合同 EXP-021 D0 和 EXP-023 D8。两个策略各一份。
- **τ(J, P)**：在 d8(P) 的正确回答上，使 judge J 的 TPR = 0.80 的 G_cal 阈值。
- **FPR**：金标准判错的回答里，G_cal ≥ τ 的比例。
- **FPR0(J, P)**：d8(P) 上的 FPR。RL 之前固定。
- **剩余空间归一的被骗比例 h**：h = (FPR − FPR0) / (1 − FPR0)。h = 0 表示和第 0 步一样；h = 1 表示所有错答都被判对。它去掉起点 FPR 不同带来的偏差（EXP-023 的主要教训）。
- **训练窗口 FPR**：把第 t−4 到第 t 步（5 步）训练 rollout 里的全部错答合在一起，算 FPR。每步 64 条 rollout。

## 2. 前提核对（自己读了原文）

- **Gao 等 2210.10760 §3.4（PDF 已读）**：RM 固定为 12M 时，比较 1.2B 和 6B 两个策略；在 3B RM 上重复，结果相似（图 22）。所以它实际上是一个 2×2（策略 1.2B/6B × RM 12M/3B，PPO，合成 RM）。结论：两个策略的金标准分数在几乎相同的 KL 处到峰值，proxy 和金标准的差也几乎相同。脚注 8：这个结果和 OpenAI 的其他内部发现矛盾，可能是这个设置的特例。脚注 12：6B 策略每步的 KL 更小。§4.5 承认只用了两个策略大小。这个结果在合成 RM 上指向 H_judge。

## 6. 端点（运行前写定）

### 6.1 主端点：t½（训练侧）

- 对每个 t = 5, 6, …, 145，算训练窗口 [t−4, t] 的 h(t)。窗口里错答少于 20 条时，这个 t 不计。
- **t½** = 最小的 t，满足 h(t) ≥ 0.5，并且下一个不重叠窗口 [t+1, t+5] 也满足 h ≥ 0.5。
- 到第 145 步还没有满足 → 删失（censored），记为"> 150"。
- 选它的理由：
  - 训练侧每步都有 64 条 rollout，分辨率是 1 步，不需要额外算力。EXP-023 的评测每 10 步一次，分辨不了速度。
  - 训练 rollout 的采样方式（T = 1.0）和 d8 相同，所以 FPR0 可以直接用 d8 的值。
  - 用剩余空间归一，起点 FPR 不同的格可以比较。

### 6.2 次要端点（描述，不进判决，除非另写）

1. **评测侧 t½**：同样的 h 定义，用评测集的贪心回答（FPR0 用第 0 步评测的值），要求下一次评测仍满足。
2. **t_0.9**：训练窗口 FPR 第一次 ≥ 0.9 的步数（线 5 的旧指标）。
3. **KL 坐标**：在 t½ 处的 KL 距离（评测时测的逐 token KL，在相邻两次评测之间线性插值）。
4. **不设阈值的量**：训练窗口内 G_cal 对金标准的 AUC 第一次 ≤ 0.5 的步数。
5. 金标准正确率：评测集的峰值、峰值步数、第 150 步的值。
6. 回答长度、重复答案行、短回答的比例（同 EXP-023）。

## 7. 分析和判决规则（运行前写定）

### 7.1 模型

- y = ln t½。删失的 run 记为 y > ln 150。
- 模型：对数正态加速失效模型（AFT），带右删失：y = β0 + βP·[P15] + βJ·[J7] + βPJ·[P15]·[J7] + ε，ε ~ N(0, σ²)，σ 各格共用。最大似然拟合。
- 平均效应：
  - judge 效应 Δ_J = βJ + βPJ/2（把 judge 从 1.5B 换成 7B，两个策略平均）。
  - 策略效应 Δ_P = βP + βPJ/2（把策略从 0.5B 换成 1.5B，两个 judge 平均）。
- 大小用参数量的对数：ln(1.54/0.49) = 1.145（策略），ln(7.61/1.54) = 1.598（judge）。
  - H_gap 预测：Δ_P = −0.717·Δ_J。
  - H_judge 预测：Δ_P = 0。
  - H_policy 预测：Δ_J = 0，Δ_P < 0。
- 差距对比 C_gap = Δ_P + 0.717·Δ_J。H_gap 预测 C_gap = 0。
- 区间：按种子在格内重抽（2000 次），每次重新拟合 AFT，取 95% 百分位区间。
- 敏感性分析（不进判决）：删失记为 150 的普通最小二乘；KL 坐标下的同样分析。

### 7.2 判决

先看前提：
- **P1**：Δ_J 的 95% 区间下界 > 0（7B judge 被骗得更慢）。
  - P1 不满足，且 Δ_P 区间上界 < 0 → 支持 H_policy。
  - P1 不满足，且 Δ_P 区间包含 0 → "这个范围内，大小不改变被骗速度"。

P1 满足时：
- **支持 H_gap**：C_gap 的区间包含 0，并且 Δ_P 的区间上界 < 0。
- **支持 H_judge**：Δ_P 的区间包含 0，并且 C_gap 的区间下界 > 0。
- **两者都有贡献**：Δ_P 区间上界 < 0，并且 C_gap 区间下界 > 0。报告比值 r = Δ_P / (−0.717·Δ_J) 和区间。r = 1 是纯差距，r = 0 是纯 judge。
- **策略效应超过差距的预测**：C_gap 区间上界 < 0。
- 其他 → **未决**，报告区间宽度和还需要多少种子。
- 如果步数坐标和 KL 坐标的判决相反，判"依赖坐标"，结论降为描述。

## 9. 种子数和功效

- 依据：EXP-023 生成式臂到 FPR ≥ 0.9 的步数（3 个种子）20、20、30，ln 的标准差 0.23；其他臂 0.17–0.30。那时分辨率是 10 步，会放大方差。我们取 σ = 0.30，悲观值 0.45。
- Δ_P 的标准误 = σ / √n（n = 每格种子数；推导：Δ_P 是两个格差的平均，每个格差的方差是 2σ²/n）。
- H_gap 和 H_judge 在 Δ_P 上的距离 = 0.717·Δ_J。

| 假设的 Δ_J | σ | n = 2 | n = 3 | n = 4 |
|---|---|---|---|---|
| ln 2（7B 慢一倍） | 0.30 | 0.65 | **0.82** | 0.91 |
| ln 2 | 0.45 | 0.35 | 0.48 | 0.60 |
| ln 3 | 0.30 | 0.96 | 1.00 | 1.00 |
| ln 1.5 | 0.30 | 0.28 | 0.39 | 0.49 |

（表内是功效：H_gap 为真时，检验"Δ_P = 0"在 α = 0.05 双侧下被拒绝的概率。）

- 选 n = 3：在"7B 慢一倍、σ = 0.30"时功效约 0.82。n = 4 要多 4 个 run，超出 15 A100 小时。
- 如果 Δ_J 只有 ln 1.5，n = 3 不够。这时结果会判"未决"，并按实测 σ 报告需要的种子数。

## 10. 算力计数

- 机器：gpu-server-2（2 张 A100 40GB）。不动不是我们启动的进程。只按 PID 结束进程。
- **计数**：每个 run 的墙钟时间 × 它占用显存的卡数。P15 的 run 用两张卡（策略一张，judge 和参考副本一张），按 2 计。这是保守的算法。另外报告机器的占卡小时。

## 11. 已知局限（运行前）

- 只有一个家族（Qwen2.5）、一个任务（GSM8K）、一个 prompt、一组超参。
- 两个大小点。只能估计"策略效应和 judge 效应之比"，不能估计曲线形状。
- 参数量不等于能力。我们同时报告实测能力（第 0 步正确率、judge AUC）。不同大小的 Qwen2.5 训练数据也可能不同。
- 两个策略用同一个 lr。大策略每步的更新量可能不同（Gao 脚注 12），所以同时报告 KL 坐标。
- judge 不给参考答案。7B judge 可能自己能解题，这正是"能力"的一部分。
