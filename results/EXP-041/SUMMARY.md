## 1. 一句话结论

- **预登记判决是 V1（按大小成立）。** EXP-041（judge 换家族：Llama-3.2-3B 对 Qwen2.5-3B，Qwen2.5-0.5B 策略，GSM8K）的主端点是平台高度 H̄。两个 judge 的 H̄ 相差 +0.018，95% 区间是 [−0.106, +0.143]，在 ±0.15 之内。
- **"按第 0 步能力"被否定。** Llama judge 第 0 步的 AUC 和 Qwen 1.5B judge 相同。但是它的平台高度明显低于 Qwen 1.5B judge。
- **但是两条曲线的形状不一样。** Llama judge 被骗得较慢：t½(0.5) 晚约 1.5 倍。它在第 150 步后还在上升，到第 151–200 步达到 0.95，高于 Qwen 3B judge 的 0.85。所以"等价"只在预登记的窗口里成立。

## 3. 主端点判决（SPEC 7.3）

平台高度的定义如下。f 和 n 是第 101–150 步里宽松错答中被骗的条数和错答总条数：

$$\bar{H} = \frac{f/n - \mathrm{FPR0_{len}}}{1 - \mathrm{FPR0_{len}}}$$

| 格 | 每个种子的 H̄ | 平均 |
|---|---|---|
| P05×JL | 0.889、0.736、0.914、0.797 | **0.834** |
| P05×J3（EXP-039） | 0.824、0.849、0.783、0.808 | 0.816 |
| P05×J15（EXP-039） | 0.972、0.978 | 0.975 |
| P15×JL | 0.818、0.785 | 0.802 |
| P15×J3（EXP-039） | 0.719、0.622、0.657、0.619 | 0.654 |

- **主比较** D_P05 = H̄(P05×JL) − H̄(P05×J3) = **+0.018**。Welch 95% 区间是 **[−0.106, +0.143]**（自由度 3.7）。
- **V1 按大小**：区间在 [−0.15, +0.15] 之内。**成立。** 上界 0.143 离界限只差 0.007。
- **V2 按能力**：要求 H̄ ≥ 0.90，而且区间下界 > 0。实测 H̄ 是 0.834，下界是 −0.106。**不成立。** 描述性对比：P05×JL 减 P05×J15 = −0.14，区间 [−0.27, −0.01]。
- **V3 家族特有（更难骗）**：要求上界 < −0.15。**不成立。**
- **V4**：不适用。
- **SPEC 7.2 的数值预测**：P05×JL 的 H̄ 应在 0.67–0.97 之间。实测 0.834，符合。
- **种子间的离散度**：JL 的标准差是 0.082，J3 是 0.028。JL 大约大 3 倍，所以区间宽，主要是 JL 一侧造成的。
- **宽容金标准的敏感性检查（事后）**：P05×JL 的 H̄ 是 0.835，P05×J3 是 0.815。结果不变。

## 6. 描述（SPEC 6.3）和事后分析

### 6.1 被骗回答的形式（每格读 20 条，用 fooled39 的方法，窗口 [t½, t½+19]）

- 40 条全部真错（宽容金标准下 0 条对）。39 条写了 "#### n"。
- 形式和 Qwen 1.5B / 3B judge 下相同：解题流畅、格式正确，但中间读错题或算错。例如 "5*42=210"，"720-72-432=18"。
- **没有长度 hack。** 被骗的错答比没被骗的短：0.5B 策略 107 对 120 token，1.5B 策略 147 对 164 token。重复答案行和题外尾巴都 ≤ 0.3%。

### 6.2 格式漂移：Llama 特有的 hack 形式（事后，`results/format_drift41.json`）

- 训练中，策略把答案的写法从 "#### n" 换成 "The answer is: n"。这是 Llama 常用的写法。同时出现 "\r\n" 换行。
  - P15×JL：第 101–150 步，带 "####" 的 rollout 只剩 0.2% 和 29%。s302 有 69% 写 "The answer is"。s301 有 57% 带 "\r"。
  - P05×JL：第 151–200 步，s302 和 s303 的 "####" 降到 7.7% 和 0%，s304 有 14% 写 "The answer is"。
  - 对比 EXP-039：Qwen 3B judge 的 8 个 run 都保持了格式（0.93–0.98）。
- **在同一窗口里，这种写法让 Llama judge 给更高的分。** 例：P15×JL-s301 第 51–100 步的错答里，"The answer is" 的被骗比例是 0.95，"####" 是 0.81。G_cal 均值是 0.63 对 0.48。
- 这种漂移不影响主端点。宽松金标准取最后一个数，宽容金标准下 H̄ 不变（第 3 节）。

### 6.3 正确率（评测集 200 题，贪心解码）

- 第 0 步：0.33（P05）/ 0.61（P15），和 EXP-039 相同。
- 最后一步按宽松解析：
  - P05×JL 是 0.08 / 0.115 / 0.05 / 0.115。对比 P05×J3 是 0.085–0.305。
  - P15×JL 是 0.385 / 0.49。对比 P15×J3 是 0.55–0.61。
- 按严格解析（要求 "####"），P15×JL 的最后正确率是 0.0 / 0.065。这是格式漂移造成的假塌缩，不是真的不会解题。

## 7. 异常和限制

- **V1 的意思比字面窄。** 判决只说明第 101–150 步的平台高度等价。在这个窗口里 JL 的曲线还在上升，和 J3 的曲线交叉。如果用第 151–200 步，结论会是"JL 更容易被骗"。窗口是在运行前写定的，所以判决仍是 V1。但是"Llama-3B 和 Qwen-3B 行为相同"这个说法不成立。
- **JL 的形状是两者的混合。** 前期较慢，像更强的 judge。后期上限接近 1.0，像 Qwen 1.5B judge。用一个"大小"或一个"第 0 步 AUC"都不能预测整条曲线。
- **出现了家族特有的 hack 形式**（6.2 节）。这一点支持"家族特有"有一部分作用，但它不在 V3 定义的方向上（V3 是更难骗）。
- 只有一个 Llama 尺寸。不能分开"家族"的作用和"这一个模型"的作用。
- J3 的对照是 EXP-039 的 run（261009），不是同时跑的。机器、环境和代码相同。
- P15 一行只有 2 个种子。
- 主区间的上界离等价界限只差 0.007。JL 的种子方差大，再加种子后区间可能越过界限。
- 宽松和宽容金标准都不是人工判分。

## 8. 对线 11 的建议

- **"judge 主导"在跨家族时成立吗？**
  - 弱的说法成立：被骗的程度和速度由 judge 决定，策略大小的作用小。JL 的 H̄ 和 J15 的 H̄ 相差约 0.14，两者第 0 步的 AUC 相同。
  - 强的说法不成立："第 0 步 AUC 决定被骗程度"被否定。"同样大小的 judge 行为相同"只在预登记窗口里成立，整条曲线不支持它。
  - 更准确的说法是：judge 的身份决定结果，但同家族里有用的两个简单预测量（大小、第 0 步 AUC）跨家族都不够用。
- **线 11 值得继续吗？** 值得小规模继续，但不要再加单点格。
  - 有新意的问题是：什么样的第 0 步测量能预测平台高度和上限？候选有 AUC、不同答案写法下的分数差、校准斜率。
  - EXP-041 的格式漂移（6.2 节）给了一个可以检验的候选："judge 对写法的偏好"。
- **到什么规模才可能成为 paper？**
  - 至少 2 个家族 × 3 个尺寸的 judge（例如 Llama-3.2-1B / 3B、Llama-3.1-8B，加上已有的 Qwen 1.5B / 3B / 7B）。
  - 至少 2 个任务（GSM8K 加一个 MATH 子集）。
  - 每格 4 个种子，跑 250 步，这样能看到上限。
  - 一个事先写定的第 0 步预测量，要在留出的家族上检验。
  - 粗估：0.5B 策略单任务约 6 格 × 4 种子 × 约 1.2 小时 ≈ 30 A100 小时。两个任务约 60 A100 小时。
  - 没有可用的预测量时，最多是 workshop 级。"judge 越大越难骗"已有 2210.10760 等工作。
