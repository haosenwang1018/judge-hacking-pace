# EXP-039 SUMMARY：GRPO 下 judge 被骗的起点，由 judge 能力决定，还是由"差距 + 地板"决定（Experiment）

261010。写法按 ASD-STE100 (simplified technical writing)。路径相对 `EXP-039/`。
依据：`SPEC.md`（含补充 1–7）、`PROCESS.md`、`results/analysis39.json`（最终分析，20 个 run）、`results/analysis39_stageA.json`（阶段 A 判决）。
关键数字都和原始文件核对过。P15×J3-s302（t½ = 41）和 P05×J7-s304（t½ = 119）用另写的最小脚本从原始 rollouts 独立复算，一致。

## 1. 结论

- **"差距 + 地板"被否定。** 它预测 0.5B 策略 + 3B judge（判长比 6.3）约等于 1.5B 策略 + 7B judge（判长比 4.9），约 90 步。实测 0.5B + 3B 只要 21–34 步。等差距对的差 = −1.26，97.5% 区间 [−1.73, −0.80]，不含 0。
- **被骗起点主要由 judge 决定。** 两个策略的起点都随 judge 变大而变晚：1.5B judge 约 20 步，3B judge 约 26–37 步，7B judge 约 90 步到删失。
- **策略大小的作用小，而且方向不一致。** 1.5B judge：没有作用（+0.08）。3B judge：1.5B 策略反而略慢（+0.36，区间含 0）。7B judge：1.5B 策略更早（−0.79，区间 [−1.38, −0.30]）。
- **预写规则的判决是 R2**（"策略效应只在强 judge 出现"）。宽容金标准下相同，不降级。
- **但 R2 的支持很脆弱。** 7B judge 下，两个策略的 h 都停在约 0.4。0.5B 策略很少越过 0.5，1.5B 策略更常短暂越过。阈值改成 0.3 时，策略效应消失（−0.10，[−0.32, 0.13]）。所以 7B 下的"策略效应"是"被骗程度的上限"不同，不是"起点更快"。
- 第二家族（离线）：1.5B judge 找到的 hack 骗不过 Llama-3.2-3B。3B、7B judge 找到的 hack 部分能骗过它。

## 2. 设置

- **策略。** P05 = Qwen2.5-0.5B 基座 + SFT（sft-s2）。P15 = Qwen2.5-1.5B 基座 + 同一 SFT 配方。第 0 步贪心正确率 0.33 / 0.61。
- **judge。** 冻结的 Qwen2.5-1.5B / 3B / 7B-Instruct。judge 不看参考答案。奖励 = 校准后的判"对"概率 G_cal。
- **训练。** GSM8K，GRPO，lr 3e-6，每步 8 题 × 8 条，β = 0，组内 std 归一化，没有格式分。同 EXP-034。
- **主端点 t½。** 宽松金标准：没有 "####" 时取最后一个数。h = (FPR − FPR0)/(1 − FPR0)，按 5 步训练窗口算。t½ 是 h ≥ 0.5、并且下一个窗口也 ≥ 0.5 的第一个步数。坐标是步数（事先写定）。
- **格点和种子。** 旧的 8 个 run（EXP-034）用保存的 rollouts 按宽松算法重算。新跑 12 个 run：
  - 0.5B + 3B × 4（200 步）；
  - 1.5B + 3B × 4（150 步）；
  - 0.5B + 7B × 2（新种子，250 步）；
  - 1.5B + 7B × 2（新种子）。
  - 阶段 C（1.5B judge 加种子）因算力上限没有跑。
- **模型。** 对数正态 AFT（加速失效模型），每格一个均值，带删失，共用 σ。ln σ 有弱先验 N(ln 0.25, 0.5²)。区间用剖面似然，主区间 97.5%（两个主比较的 Bonferroni 水平）。
- **3B judge 的静态闸门**（`results/static_J3.json`）：AUC(G) 0.850 / 0.808。它在 1.5B judge（0.744 / 0.678）和 7B judge（0.889 / 0.873）之间。闸门通过（≥ 0.60）。

### 3.5 "余量"解释：共同错题上的 h

共同错题是：第 0 步时，两个策略的全部样本都答错的题（324 道）。

| judge（0.5B / 1.5B 策略） | 第 1–50 步 | 第 51–100 步 | 第 101–150 步 |
|---|---|---|---|
| 1.5B | 0.66 / 0.58 | 0.94 / 0.92 | 0.98 / 0.98 |
| 3B | 0.49 / 0.35 | 0.70 / 0.56 | 0.83 / 0.66 |
| 7B | 0.12 / 0.13 | 0.32 / 0.40 | 0.37 / 0.34 |

- 在所有格里，共同错题上的 h 和全部题上的 h 很接近。
- 7B judge 下，共同错题上看不到 1.5B 策略的优势。所以 7B 下的策略效应不能排除"余量"解释。

### 3.6 hack 的形式（每格读 20 条被骗回答）

- **1.5B 和 3B judge（80 条）。**
  - 全部真错，17–20 条写了 "#### n"。
  - 形式是流畅、自信、格式对的解题，中间读错题或算错。例："3 * 2000 - 500 = 550"，"$58 + $116 + $464 = $648"。
  - judge 不检查算术。
- **7B judge（40 条）。**
  - 12–13 条写了 "####"，其余丢了格式，用文字给答案。
  - 按宽容金标准，0.5B 策略有 2 条、1.5B 策略有 4 条其实答对了。宽松解析取错了数。
- **没有长度 hack。** 每一格里，被骗的错答都比没被骗的错答短。例：3B judge 下 124 对 146 token，7B judge 下 142 对 152 token。没有重复答案行，几乎没有题外尾巴。
- **格式丢失。**
  - 7B judge 的 8 个 run 里，有 5 个最后的格式率 ≤ 0.09。
  - 1.5B judge 下，1.5B 策略有 1 个 run 丢了格式。
  - 3B judge 的 8 个 run 都保持格式（0.93–0.98）。

## 5. 读法

- **最稳的发现。** 在 0.5–1.5B 策略、1.5–7B judge 的范围里，起点主要由 judge 决定。"只看判长比，加一个地板"解释不了数据。等差距对差了约 3.5 倍。
- **3B judge 这一行是关键证据。** 0.5B 策略的判长比是 6.3，比 1.5B 策略 + 7B judge 的 4.9 还大，但它快了约 3.5 倍。
- **7B judge 下的策略效应是"上限"效应。**
  - 7B judge 不会被骗到底，h 停在约 0.4。对比：1.5B judge 到约 1.0，3B judge 到 0.65–0.85。
  - 0.5 的阈值正好落在这个平台上，所以起点对小的差别很敏感。
  - "更强的策略更早骗过强 judge"是说过头。能说的是：强 judge 下，大策略被骗的上限可能略高（约 0.04）。这个差在共同错题上看不到。
- **3B judge 下大策略略慢（+0.36，p 0.07）。** 一个可能的原因：1.5B 策略错答更少（第 0 步错答率 0.53 对 0.81），hack 的信号弱。这是推测，没有检验。
- **和已有工作的关系。**
  - "judge 越大，hack 越晚"和 2210.10760、2603.12246、2608.17776 同向。
  - 新的部分有两点。第一，在冻结 LLM judge、不给参考答案的设置里，用交叉格点和等差距对，排除了"只看差距"的解释。第二，强 judge 下被骗程度有上限。

## 6. 局限

- 一个家族（Qwen2.5）、一个任务（GSM8K）、一个 prompt、一组超参。第二家族只做了离线重打分。
- 策略只有两个尺寸。3B 策略的全参数训练放不进 40 GB 卡。
- 每格 2–4 个种子。1.5B judge 一行只有旧的 2 个种子。
- 起点正确率不同（0.33 对 0.61）。"MATH → GSM8K"的偏离已在 SPEC 第 4 节登记。7B 下的"余量"解释没有排除。
- 宽松和宽容金标准都不是人工判分。
- 不同格的运行步数不同（150 / 200 / 250）。AFT 按每个 run 自己的删失点处理。
- 有两处改动是在看过部分结果之后做的：
  - SPEC 补充 2（宽容金标准）：在任何 3B 结果之前。
  - SPEC 补充 7（τ 处浮点并列）：看过 2 个 run 之后。所有 t½ 不变，旧算法的结果也报告了。
- σ 的先验是在看过旧 8 个 run 之后、任何 3B 数据之前定的。不加先验的结果几乎相同。
- 3B judge 的许可是 Qwen Research License。
