## 5. 检验（来源 `results/analysis46.json` → `test`）
### 5.1 排序
"符号调整后的 ρ"指的是：预测量乘上预期符号后，和结果量之间的 Spearman ρ。正值表示方向正确。
- 计算方法：
  - 结果量是 O1 = E1，O2 = t½(0.3) 的 AFT μ，O3 = t½(0.5) 的 μ，O4 = E5。
  - 如果一对格结果量之差的种子层 Welch 95% 区间含 0，这一对算"并列"，不计入。

| 预测量 | ρ O1 | ρ O2 | ρ O3 | ρ O4 | 非并列对排对数（O1 / O2） |
|---|---|---|---|---|---|
| P1 | 0.5 | 0.5 | 0.5 | 0.5 | 2/3，2/3 |
| B1 AUC | 1.0 | 1.0 | 1.0 | 1.0 | 3/3，3/3 |
| B2 FPR0 | 0.5 | 0.5 | 0.5 | 0.5 | 2/3，2/3 |
| B3 风险分 | 0.5 | 0.5 | 0.5 | 0.5 | 2/3，2/3 |

- JL8 对 JO7 这一对不并列：
  - O1 差的区间是 [−0.323, −0.037]。
  - O2 差的区间是 [0.137, 0.443]。
  - JO7 被骗得更深、更快。
- P1 认为 JL8 更容易被骗（0.689 对 0.437），所以排错了。B2、B3 也排错了这一对。
- O3 上，JO1 对 JO7 是并列。
- 下面这些只作描述：把 4 个旧 P05 格和 3 个新 P05 格合成一行，7 个 judge 的 ρ 如下。其中 4 个格在选预测量时已经看过。
  - P1：O1 0.82，O2 0.71。
  - B1：O1 0.89，O2 0.79。

### 5.2 锁定拟合的预测
- 模型：结果 = a + b × 预测量 + c × [P15]，在 8 个旧格上拟合。系数来自 `FINAL_PREDICTOR.json`。新格是 P05，所以 c 不起作用。
- 95% 预测区间用 8 格的设计矩阵算，自由度 5。

| 预测量 | O1 MAE | O2 MAE | O1 预测（JL8 / JO1 / JO7） |
|---|---|---|---|
| P1 | 0.188 | 0.249 | 0.829 / 1.249 / 0.705 |
| B1 | 0.095 | 0.247 | 0.656 / 0.883 / 0.691 |

| B3 | 0.096 | 0.250 | 0.662 / 0.925 / 0.638 |

- O1 的观测值是 0.673 / 0.989 / 0.853。
- 所有预测量在 3 个格上的观测值，都在 95% 预测区间内。原因是区间很宽，例如 P1 对 JL8 的区间是 [0.38, 1.27]。
- 去掉 JO1 以后，P1 的 O1 误差是 0.156（JL8）和 0.148（JO7）。B1 是 0.017 和 0.162。P1 仍然不比 B1 好。
- O2 上四个预测量的误差几乎相同（0.247–0.250）。

### 5.3 判决
- P1 的两个 ρ 都大于 0，这一条满足。
- P1 的 O1 MAE 是 0.188，不小于最好基线的 0.095，这一条不满足。所以 P1 不通过。
- 不管怎么读规则，P1 都没有胜过 B1。B1 在 4 个结果量上都完全排对。
- EXP-047 SUMMARY 有一条协调 agent补充：B1 在 O1 上每一行也完全排对。新数据和这一点一致。P1 在 EXP-047 里胜过 B1，靠的只是跨策略合并的 8 格 ρ。本实验只有 P05 一行，测不到这个优势。

## 6. 跨家族风险（EXP-047 SPEC 第 10 节）
- P1 几乎等于 G_cal 的系数 a，也就是 judge 的 logit 尺度（EXP-047 SUMMARY 第 8 节）。
- 新 judge 的 G_cal 系数 a 分别是：JL8 0.731，JO1 1.604，JO7 0.468（`EXP-046/data/readouts/readouts_<J>_P05.json`）。
- 在 OLMo 家族内，P1 的顺序是 JO1 > JO7，被骗的顺序也是 JO1 > JO7，两者一致。
- 跨家族时，OLMo-7B 的 logit 尺度比 Llama-8B 宽（P1 更小），但它被骗得更深。
- 所以 P1 的失败出现在跨家族这一对上。这正是 EXP-047 SPEC 第 10 节说的风险。
- B2、B3 也排错了这一对，所以这个失败不只属于 logit 尺度。

## 10. 结论
- EXP-047 只用旧数据选出 P1。它在新的、留出的 judge 上没有胜过 AUC。
- P1 方向对，但锁定拟合的误差约为基线的两倍，而且排错了一对跨家族的格。
- 第 0 步的 AUC（B1）在 11 个 P05 和 P15 格的行内排序里一直很好。目前最简单的说法是：在同一个策略下，AUC 已经够用。
- "logit 尺度窄的 judge 更容易被骗"这个假设，在家族内部还成立，跨家族不成立。
- 下一步可以考虑：
  1. 加 P15 一行，或者加更多家族，让跨策略、跨家族的比较有更多格。
  2. 在家族内部检验 P1，并且在 P1 范围内的 judge 上检验，避免外推。
